Collectivement, ces livrables couvrent les trois temps de la couverture, à des degrés  
divers.  Avant :  promotion,  programme,  inscription,  sponsors,  contact.  Pendant :  
programme, badge, scan, espace participant. Après : les données restent, le site peut  
servir  de  vitrine  de  l’édition  ;  en  revanche,  le  compte  rendu  éditorial  (galerie, 
actualités, replay) n’est pas encore un module à part entière.
4.1.2. Tests et validation
Les tests ont été principalement fonctionnels et exploratoires, complémentaires d’une 
validation de build ( npm run build ) et d’un linting ESLint. L’absence d’une batterie  
automatisée complète (tests unitaires React Testing Library, tests E2E Cypress ou  
Playwright) est une limite, compensée par des scénarios manuels répétés à chaque  
incrément.
